# moonbitJobShop 设计说明

## 目标

构建一个面向 MoonBit 生态的作业车间调度基础库，覆盖制造场景中常见的工件、工序、设备、工艺路线、换型时间和交期约束，并输出可消费的调度结果与统计指标。

## 范围

首版提供领域模型、输入校验、固定/可选设备路线、基于最早可行时间的启发式调度、目标函数、甘特图事件、设备利用率和延期统计。算法通过统一 `Solver` 接口暴露，后续可加入局部搜索、遗传算法、禁忌搜索、动态插单、故障重调度和 Pareto 优化。

## 架构

`model` 保存公开领域类型；`schedule` 负责可行时间计算与资源占用；`objective` 负责独立指标；`solver` 负责求解器协议及启发式实现；`report` 将内部结果整理为稳定的展示数据。包之间只通过公开类型和函数协作，避免把算法实现与领域模型耦合。

## 约束与错误处理

空工件、空工序、负时长、无效设备和无效路线在构造/校验阶段返回明确错误。调度器拒绝未覆盖全部工序的方案，并保证同一设备上的区间不重叠；换型时间计入相邻工序之间的开始时间。

## 测试与质量门禁

测试覆盖模型校验、固定路线、可选路线、换型时间、交期延期、目标计算和报表。CI 执行 `moon fmt --check`、`moon check --deny-warn`、`moon info --deny-warn`、`moon test --deny-warn` 与 `moon test --target native --deny-warn`。

## 生态边界

项目专注制造排程数据结构和优化算法，不提供机构计算、几何建模或通用数值求解器；与 MoonMech 的能力边界清晰。仓库使用 MIT License，并通过 README 记录来源、差异化和公开开发计划。
