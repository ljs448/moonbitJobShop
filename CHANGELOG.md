# Changelog

## 0.2.0 - 2026-08-24

- Added calendar-aware dispatch, dynamic rescheduling and rolling-window analysis.
- Added deterministic local, tabu, genetic, annealing and ruin-and-recreate search APIs.
- Added Pareto analysis, constraint policies, capacity projections, KPI dashboards and operational reports.
- Added reproducible benchmark datasets, benchmark CLI, expanded boundary tests and cross-platform CI.

## 0.1.0 - 2026-08-08

- Added manufacturing domain model and validation.
- Added deterministic earliest-feasible dispatch with alternative machines and setup times.
- Added objectives, utilization, load-balance, tardiness and Gantt events.
- Added demo CLI, strict CI, project documentation and MIT License.
